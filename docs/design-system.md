# Mooncell 设计规范

## 颜色与文字

- 颜色通过 `index.css` 的运行时变量定义，两套主题共用 `@theme inline` 工具类。
- 组件使用 `text-ink`、`text-muted`、`bg-surface`、`border-border` 等语义类；TSX 不写十六进制颜色。
- 强调色用于主要操作、选中态与进度。普通正文链接使用正文色与下划线，辅助状态优先使用中性色。
- 成功、警告与危险使用对应语义令牌，同时提供文字或图标，不能仅靠颜色区分。
- 海报文字统一使用 `media-ink` / `media-muted` 配合 `.media-scrim`，保持两主题中的可读性。
- 字号阶梯为 12 / 13 / 14 / 16 / 22 / 32+ px。最小 12px；辅助文字也遵循此下限。
- 12 / 13 / 14px 分别使用 `text-caption` / `text-small` / `text-body`。

## 形状与层级

- 控件 8px (`rounded-control`)、卡片 12px (`rounded-card`)、面板与海报 16px (`rounded-panel`)。
- 胶囊使用 `rounded-full`；控件内嵌内容允许使用 6px 的 `rounded-inset`。
- 常规卡片、搜索栏和空状态使用 `surface`，不使用背景模糊。
- 背景模糊仅用于固定顶栏及浮层（弹窗、菜单、提醒中心）。图片上的文字用静态渐变衬底。
- 应用工作区使用静态 CSS 渐变。登录页可以保留局部品牌效果，但必须遵循减少动态效果。

## 交互与动效

- 位移、缩放、旋转、透明度与布局变化统一引用 `lib/motion.ts` 的 Spring 预设。
- `snappy` 用于导航/浮层，`gentle` 用于入场/展开，`layout` 用于重排，`press` 用于按压。
- CSS 时长过渡只用于颜色和边框色；播放时间、倒计时等业务进度不属于入场动效。
- 减少动态效果下立即呈现终态；同一会话重访页面时不重复逐项入场。
- 有内部控件的卡片不因悬停整体位移；整块链接的海报可保留轻微反馈。
- 所有操作有可见入口、键盘焦点与可理解的名称。容器本身无动作时不添加 Tab 焦点。
- 错误提示持续保留直至用户关闭；成功提示可自动关闭。

## 验证

- `scripts/visual-check.cjs` 覆盖森林绿/深海蓝、四个视口、所有计划页面和认证页。
- 修改令牌映射时，以同一构建与固定夹具逐像素对比，确保类名迁移不改变外观。
- 性能采集使用 `scripts/frontend-perf.cjs`，保留硬件与无头浏览器限制，不能把 rAF 当作实际呈现帧率。
