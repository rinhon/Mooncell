# Mooncell 使用指南

[返回 README](../README.md) · [开发指南](DEVELOPMENT.md)

本文说明订阅、自动整理与异常处理的具体规则。部署步骤见 [README 快速启动](../README.md#快速启动)。

## 订阅与刷新

通过订阅卡片的“编辑”按钮或右键菜单，可修改番剧名称、RSS 地址、排除关键词、季度、类型、启用状态和刷新间隔。

- 修改番剧名称或季度会同步已有系统下载任务，保留 TMDB 关联和集数，具体见下方说明。
- 排除关键词用于后续发布筛选。
- 各订阅使用自身的刷新间隔；修改设置页的全局刷新间隔会统一覆盖已有订阅。
- 手动或定时刷新后，解析通过的条目自动进入持久化下载队列；已有条目也会补投，重复刷新不会重复添加相同 info-hash。

自动投递需要启用 qBittorrent，并使用 `downloader_managed` 策略（界面默认值）。aria2 当前仅支持连接配置与测试。

新任务投递时自动添加番剧名称标签，qB 中的任务名保持原样。修改番名时同步标签，只移除 Mooncell 记录的旧番名标签，保留其他标签；旧任务没有标签记录时仅补充新标签。番名中的英文逗号转为全角逗号，避免被拆成多个标签，连续空白合并为空格。

### 修改番名与季度并同步已有下载

在订阅编辑中修改番名或季度后，系统更新数据库中的媒体库名称及季度，并通过后台迁移同步 qBittorrent 中的番剧标签、文件名和保存路径，保留 qB 任务原名。只改番名时保留各任务的原季度；同时修改时，先确定新番名根目录，再生成新季度下的文件路径，例如 `旧番名\Season 01\旧番名 S01E05.mkv` 改为 `新番名\Season 02\新番名 S02E05.mkv`。集数（包括逐文件人工修正）及字幕语言选择保持不变。0 表示特别篇，清空季度时从各条目的原始发布标题重新识别季度。

迁移前持久化旧番名、旧季度、旧计划和原路径，始终按旧快照定位原文件，不会用新番名查找旧目录。后台确认原目录和文件归属后暂停任务，将单个种子移入媒体库 `.mooncell/season-change/` 下的独立暂存目录，逐文件改名后移入目标目录，最后同步番剧标签并恢复原来的运行或暂停状态。合集有外层目录时，qB 保存路径为新番名目录，内部使用新季度目录。此过程保留种子和 info-hash，不删除媒体文件或重新下载。

番名变更时，已有海报、背景图与 Clearlogo 会复制到新番名目录并更新数据库引用；原图保留，供共享旧目录的其他订阅使用。新目录存在内容不同的同名图片时，整次修改会被拒绝，不覆盖已有图片；TMDB 关联及作品元数据不重新刮削。

迁移进度保存在数据库中，服务重启、下载器离线或临时接口失败后可继续。在下载中心查看“同步媒体库中”或“媒体库迁移异常”及详细原因；存在同名目标、其他任务共享文件或手动改动路径时，停止文件操作，解决冲突后自动重试。迁移期间不能改成另一个番名或季度，也不能人工批准或重新下载对应任务。修订版替换尚未完成时，保存番名或季度变更会被拒绝。已忽略、被新版取代及在其他目录手工添加的种子不会接管迁移。

## 自动下载与文件整理

### 媒体库与路径映射

在设置中选择媒体库目录。该目录必须能被下载器访问；容器路径不同时，配置下载器的本地 / 远程根目录映射，媒体库必须位于映射范围内。

当前自动整理通过 qBittorrent Web API 重命名和移动文件，保留做种，不执行硬链接或复制策略。系统不会接管用户已在其他目录手工添加的相同种子。

### 元数据与目录命名

磁力链接先在媒体库的 `.mooncell/<info-hash>` 下获取元数据。后台读取真实文件列表后，按以下规则整理：

| 种子结构 | 整理方式 |
| --- | --- |
| 无外层文件夹 | 保存至 `番名/Season 02/番名 S02E05.mkv` |
| 有共同外层文件夹 | 将外层改为 `Season 02`，放入番名目录；视频按相同规则命名 |
| 多视频 | 逐文件识别集数并保留原视频扩展名 |

季度优先采用订阅填写值。新任务在获取磁力元数据后暂停，确认文件筛选和目录整理完成后才开始下载。旧版下载器若不支持元数据自动暂停，后台首次读取到文件列表时会暂停任务；已经下载的文件不会被删除。

后台每 5 秒继续处理任务，等待元数据、服务重启或临时接口失败后均可继续。下载中心显示自动化状态与异常原因；低置信度条目、无法识别集数和不符合修订版升级条件的同集冲突进入人工审核。

整理、番名/季度迁移和修订版替换结束后，会清理 `.mooncell` 内遗留的空目录；后台每分钟补清理一次历史遗留。只删除空目录，保留所有文件、目录链接及 qB 当前保存路径和下载临时路径使用中的目录。下载器离线或远程路径未映射到本机时保留目录，等待后续清理。

### 字幕语言选择

同一集的语言版本按以下优先级选择，不同时下载多个语言版本：

```text
简中独立版 → 简繁内封版 → 繁中独立版
```

支持识别文件名和目录中的 CHS/CHT、GB/BIG5、简中/繁中、zh-Hans/zh-Hant、简繁内封等标记。低优先级版本设为“不下载”并跳过重命名；只有繁中时正常下载繁中。

### 修订版选择与替换

支持 `[01]`、`[01v2]` 等方括号集数。同一订阅内，作品、季度、集数、字幕组、分辨率及字幕语言 / 封装规格一致的单集发布，首次刷新只投递最高修订号，不依赖 RSS 顺序或发布时间。旧记录显示“已被新版取代”，后续刷新不会再次投递；缺少可靠身份信息时仍需审核。

系统管理的旧版入库后出现更高修订版，自动替换流程如下：

1. 新版先在 `.mooncell/<新 info-hash>` 中独立下载。
2. qBittorrent 确认所选文件完整，且未处于校验或异常状态后，暂停旧种子，并将旧文件移至独立备份目录。
3. 将新版移入媒体库，确认入库后再删除备份目录中的旧种子和旧文件。
4. 新版入库失败时恢复旧版，保留新版暂存文件并进入审核。

各阶段持久化保存，服务重启可继续。合集、跨订阅、规格不同、目录被手动改变或多个任务共享文件时，不自动替换。

## 人工审核

“审核”页读取真实待审核发布和下载整理异常，支持搜索、重新解析、忽略及修正批准。

| 操作 | 行为 |
| --- | --- |
| 修正批准 | 可修正媒体库番名、季度和集数；特别篇可使用季度 0，修正仅对该发布生效 |
| 逐文件修正 | 合集或无法识别文件集数的任务，获取种子元数据后可逐文件填写集数或选择跳过 |
| 批准 | 继续下载队列，仍检查目标文件冲突，不覆盖已有同名文件 |
| 忽略 | 暂停已有任务并保留文件，后续订阅刷新不会重复投递该条目 |
| 重新解析 | 更新解析证据，仍需明确批准 |

操作及批准前后的解析信息保存到事件日志。

## TMDB 配置

在“设置 → TMDB 元数据与图片”中填写 **TMDB API 读访问令牌**或 **API 密钥**，任选其一；同时配置时优先使用读访问令牌。凭据可在 [TMDB 账户 API 设置](https://www.themoviedb.org/settings/api)中获取，保存后立即用于后续请求。

- 搜索、作品详情和图片列表通过官方 v3 API 获取。
- 凭据使用应用的 `MOONCELL_SECRET_KEY` 加密后保存在数据库中，设置页面仅显示配置状态。
- 输入留空保留原值；勾选清除后保存，可移除对应凭据。
- 已有订阅不会自动重抓；在番剧页点击“重新刮削”可更新元数据和图片。
- 总集数取电视详情的 `number_of_episodes`，表示作品总集数，不按订阅季度筛选。
- 首次运行新版本时会自动创建 TMDB 配置表。

## 季度追番日历

### 季度与刷新

追番日历从 yuc.wiki 获取季度新番，按北京时间将当前月份映射到 `YYYY01`、`YYYY04`、`YYYY07`、`YYYY10`。例如 2026 年 9 月读取 `202607`，10 月 1 日起读取 `202610`。

后端运行期间自动检查季度切换；停机错过节点时，下次启动会补抓当前季度。日历包含周一至周日和“其他放送”，后者收录网络放送等非固定星期的作品，显示源站提供的放送日期与说明。

每季度页面成功保存后不再重复抓取，失败的封面单独重试下载。旧版缓存会在后台检查或首次访问时重新抓取一次，补齐“其他放送”，保留已有条目 ID、收藏和封面；补抓失败时仍可浏览旧数据，15 分钟后重试。完成补齐后，浏览日历只读取本地缓存。上一季度按钮首次访问尚未缓存的季度时，会抓取并保存该季度。

### 缓存位置

番名、星期、播出时间保存到 `backend\data\calendar\YYYYMM\season.json`，封面保存在同目录。Docker 中随 `/app/data` 数据卷持久化，可通过 `MOONCELL_CALENDAR_CACHE_PATH` 修改缓存目录。

播出时间保留源站原文，包括表示次日凌晨的 `24:00`、`25:00` 等写法。

### 抓取失败处理

源站暂不可用或尚未发布时，15 分钟后重试。页面和封面请求默认使用环境代理；HTTPS 证书校验失败时会保留证书校验，自动尝试直连一次。

若仍然失败，请检查系统时间及源站、代理证书。重启后端可清除失败后的 15 分钟等待并立即重试。
