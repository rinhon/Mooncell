# Mooncell 使用指南

[返回 README](../README.md) · [开发指南](DEVELOPMENT.md)

本文说明订阅、自动整理与异常处理的具体规则。部署步骤见 [README 快速启动](../README.md#快速启动)。

## 订阅与刷新

“添加订阅”弹窗包含两个标签页：

- **RSS 订阅**：原有的 RSS 解析、TMDB 匹配和持续刷新流程。
- **磁力合集**：粘贴单个 BT v1 磁力，解析原始作品名称和文件清单，选择 TMDB 电视节目并确认季度后添加下载。名称末尾数字仅提供季度建议，以 TMDB 为准。

磁力预览使用 qBittorrent 5.2+ 的元数据接口，解析阶段只获取文件清单。保存后进入现有下载队列，并在后台刮削作品信息、海报和其他图片。合集以独立来源显示在订阅、番剧和下载中心，不执行 RSS 刷新；修改名称和季度仍可同步已有下载。

合集按文件名中的集数整理至 `作品名\Season 02\作品名 S02E01.mkv`。明确标记的 NCOP、NCED、菜单、特典等跳过；与正片同目录同名的外挂字幕随正片改名，简繁字幕分别使用 `.zh-Hans`、`.zh-Hant`。不匹配的附件跳过。一个合集对应一季；无法识别的正片或重名目标会阻止保存并显示原因，整理时若实际目录发生变化则进入审核，不覆盖已有文件。

通过订阅卡片的“编辑”按钮或右键菜单，可修改番剧名称、RSS 地址、排除关键词、季度、类型、启用状态和刷新间隔。

- 修改番剧名称或季度会同步已有系统下载任务，保留 TMDB 关联和集数，具体见下方说明。
- 排除关键词用于后续发布筛选。
- 各订阅使用自身的刷新间隔；修改设置页的全局刷新间隔会统一覆盖已有订阅。
- 手动或定时刷新后，解析通过的条目自动进入持久化下载队列；已有条目也会补投，重复刷新不会重复添加相同 info-hash。

自动投递需要启用 qBittorrent，并使用 `downloader_managed` 策略（界面默认值）。aria2 当前仅支持连接配置与测试。

HTTP / HTTPS 种子链接由 Mooncell 使用订阅代理获取种子文件，再上传给 qBittorrent，因此 qB 无需直接访问种子源站。磁力链接仍直接提交给 qB 获取元数据。订阅代理留空时，Mooncell 直连获取种子文件。

新任务投递时自动添加番剧名称标签，qB 中的任务名保持原样。修改番名时同步标签，只移除 Mooncell 记录的旧番名标签，保留其他标签；旧任务没有标签记录时仅补充新标签。番名中的英文逗号转为全角逗号，避免被拆成多个标签，连续空白合并为空格。

### 修改番名与季度并同步已有下载

在订阅编辑中修改番名或季度后，系统更新数据库中的媒体库名称及季度，并通过后台迁移同步 qBittorrent 中的番剧标签、文件名和保存路径，保留 qB 任务原名。只改番名时保留各任务的原季度；同时修改时，先确定新番名根目录，再生成新季度下的文件路径，例如 `旧番名\Season 01\旧番名 S01E05.mkv` 改为 `新番名\Season 02\新番名 S02E05.mkv`。集数（包括逐文件人工修正）及字幕语言选择保持不变。0 表示特别篇，清空季度时从各条目的原始发布标题重新识别季度。

迁移前持久化旧番名、旧季度、旧计划和原路径，始终按旧快照定位原文件，不会用新番名查找旧目录。后台确认原目录和文件归属后暂停任务，将单个种子移入媒体库 `.mooncell/season-change/` 下的独立暂存目录，逐文件改名后移入目标目录，最后同步番剧标签并恢复原来的运行或暂停状态。合集有外层目录时，qB 保存路径为新番名目录，内部使用新季度目录。此过程保留种子和 info-hash，不删除媒体文件或重新下载。

番名变更时，已有海报、背景图与 Clearlogo 会复制到新番名目录并更新数据库引用；原图保留，供共享旧目录的其他订阅使用。新目录存在内容不同的同名图片时，整次修改会被拒绝，不覆盖已有图片；TMDB 关联及作品元数据不重新刮削。

迁移进度保存在数据库中，服务重启、下载器离线或临时接口失败后可继续。在下载中心查看“同步媒体库中”或“媒体库迁移异常”及详细原因；存在同名目标、其他任务共享文件或手动改动路径时，停止文件操作，解决冲突后自动重试。迁移期间不能改成另一个番名或季度，也不能人工批准或重新下载对应任务。修订版替换尚未完成时，保存番名或季度变更会被拒绝。已忽略、被新版取代及在其他目录手工添加的种子不会接管迁移。

## 番剧与电影详情

点击番剧卡片或行卡的海报、标题，以及首页画廊、最近添加和提醒中心的“查看番剧”，可进入 `/shows/{source_id}` 详情页。每个详情对应一个订阅源；相同 TMDB 作品的不同订阅或季度分别展示。旧地址 `/shows?id=6` 自动跳转新详情地址，列表搜索 `/shows?q=...` 保持可用。

详情展示真实元数据、剧情简介、作品海报与素材状态。缺失的评分、日期、总集数不会补造；电影不显示总集数。返回入口保留从番剧列表进入时的搜索、卡片 / 列表视图与滚动位置，直接打开详情时返回番剧列表。

桌面双栏布局中，左侧海报在滚动时保持可见，并根据视口高度缩放；右侧季度 / 订阅信息 Tab 滚到顶部导航下方后吸顶，列表继续随页面滚动。向上滚回 Tab 原位置时自然解除吸顶，重新显示剧情等上方内容。窄屏沿用紧凑的海报排版，Tab 同样支持吸顶。

详情内容按作品文件夹中的实际视频分季度显示，例如“第 2 季 · 12”。优先打开订阅指定季度；有多个季度时可切换，特别篇显示为独立季度。每一行对应一个实际视频文件，显示已识别的集数、原文件名和文件大小；电影显示“影片”，无法识别集数的文件直接显示文件名。图片、字幕、下载临时文件与隐藏暂存目录不进入列表。

列表取消分页，向下滚动时每批追加 12 个文件，并复用番剧卡片页的滑入动画。优先显示视频同目录中与文件名对应的单集缩略图（`视频名-thumb.jpg`，其次 `视频名.jpg`，也支持 JPEG、PNG、WebP）；没有单集图时回退到作品背景图或海报。“本地文件”表示文件存在，不等于下载器校验完成；实时下载状态仍在下载中心查看。目录尚未建立或无法访问时显示相应提示，不再用发布记录或整理计划虚构集数。文件列表每 15 秒后台更新，已有行不重复播放入场动画。

### 本地图片扫描

默认关闭自动扫描，点击设置页“保存路径 → 本地图片扫描 → 立即扫描”后执行一次；页面仅在扫描进行时定时查询进度，完成后停止轮询。需要自动扫描时，可将 `MOONCELL_LIBRARY_SCAN_INTERVAL_SECONDS` 配为正数（最少 10 秒），服务启动 5 秒后开始；设为 0 或负数关闭。扫描同步文件路径和缓存版本，不读取 NFO、不更改你确认的 TMDB ID，也不联网刮削或生成图片。

作品根目录支持 `poster/folder/cover`、`fanart/backdrop/background`、`clearlogo/logo`，格式为 JPG、JPEG、PNG、WebP，文件名不区分大小写；同名不同格式时选修改时间最新的文件。单集缩略图只关联同目录中真实存在的视频。BIF 视频预览暂不扫描。

扫描检测到新增、覆盖或删除时更新数据库，并实时刷新番剧、订阅和详情页面；未发生变化时不重复写入事件。目录未挂载或读取失败时保留已有记录，下一轮重试；不跟随子目录链接，也不修改或删除媒体文件。图片缺失时不会凭空补图，需要重新刮削或放回正确图片。

原始发布记录 API `/shows/{source_id}/releases` 与 `/items` 保留兼容，详情页改用只读媒体库接口 `/shows/{source_id}/library`，不再显示原始资源分页列表。

“订阅信息”可查看来源类型、启用状态、季度、刷新间隔、最近检查和排除词。磁力合集隐藏 RSS 定时刷新和检查字段。“打开文件夹”位于详情页的“更多操作”下拉菜单。管理图片、编辑订阅、重新刮削及 RSS 刷新复用已有功能，图片上传和后台刮削完成后自动刷新详情。

## 自动下载与文件整理

### 详情页单集改名

在订阅详情页的季度列表中，点击视频右侧的“改名”，修改文件名后保存。Mooncell 通过 qBittorrent Web API 改名并保留做种；目录和视频扩展名不变，不覆盖同名文件。文件必须已下载完成，且能根据系统下载任务及路径映射定位到已启用的 qBittorrent 下载器。播放期间需先关闭该作品的播放页面。

远程改名尚未完成时显示“改名中…”，确认实际路径后自动刷新列表，并保留续播进度和缩略图关联。请求超时或 Mooncell 重启后，后台继续确认结果。此次操作只修改选中的视频文件，不自动改名外挂字幕。

### 媒体库与路径映射

在设置中选择媒体库目录。该目录必须能被下载器访问；容器路径不同时，配置下载器的本地 / 远程根目录映射，媒体库必须位于映射范围内。

“选择文件夹”按路径缓存目录列表，5 分钟内重复打开或展开复用缓存；过期后在下次打开或展开时更新，不定时轮询，也不因切回窗口而刷新。未使用的目录缓存保留 30 分钟。新建文件夹或磁盘变化后，可点击“刷新文件夹”立即更新磁盘与已展开的目录，收起的分支留到下次展开时更新；保存发现路径失效或无权访问时也会刷新目录树。

当前自动整理通过 qBittorrent Web API 重命名和移动文件，保留做种，不执行硬链接或复制策略。系统不会接管用户已在其他目录手工添加的相同种子。

### 元数据与目录命名

磁力链接先在媒体库的 `.mooncell/<info-hash>` 下获取元数据。后台读取真实文件列表后，按以下规则整理：

| 种子结构 | 整理方式 |
| --- | --- |
| 无外层文件夹 | 保存至 `番名/Season 02/番名 S02E05.mkv` |
| 有共同外层文件夹 | 将外层改为 `Season 02`，放入番名目录；视频按相同规则命名 |
| 多视频 | 逐文件识别集数并保留原视频扩展名 |

季度优先采用订阅填写值。新任务在获取磁力元数据后暂停，确认文件筛选和目录整理完成后才开始下载。旧版下载器若不支持元数据自动暂停，后台首次读取到文件列表时会暂停任务；已经下载的文件不会被删除。

后台每 5 秒继续处理任务，等待元数据、服务重启或临时接口失败后均可继续。下载中心显示自动化状态与异常原因；低置信度条目、无法识别集数和不符合修订版升级条件的同集冲突进入人工审核。

种子源站连接失败、网络超时、下载器接口故障或拒绝投递时，保留任务及整理进度，按 30 秒、1 分钟、2 分钟、4 分钟、8 分钟、15 分钟退避重试，此后每 15 分钟再试。等待时间和连续失败次数保存在数据库中，服务重启不会重置。下载中心显示“等待自动重试”、中文原因和预计重试时间；修复代理或下载器配置后可点击“立即重试”，无需重新创建下载任务。持续相同错误只记录一次，处理恢复时另记中文恢复日志。

每次投递前先通过 info-hash 查询下载器，避免已接收任务但响应丢失时重复添加。已从 qB 手动移除的任务仍不会自动重新添加，需要明确使用重新下载功能。

整理、番名/季度迁移和修订版替换结束后，会清理 `.mooncell` 内遗留的空目录；后台每分钟补清理一次历史遗留。只删除空目录，保留所有文件、目录链接及 qB 当前保存路径和下载临时路径使用中的目录。下载器离线或远程路径未映射到本机时保留目录，等待后续清理。

### 字幕语言选择

同一集的语言版本按以下优先级选择，不同时下载多个语言版本：

```text
简中独立版 → 简繁内封版 → 繁中独立版
```

支持识别文件名和目录中的 CHS/CHT、GB/BIG5、简中/繁中、zh-Hans/zh-Hant、简繁内封等标记。低优先级版本设为“不下载”并跳过重命名；只有繁中时正常下载繁中。

### 修订版选择与替换

支持 `[01]`、`[01v2]` 等方括号集数。同一订阅内，作品、季度、集数、字幕组、分辨率及字幕语言 / 封装规格一致的单集发布，首次刷新只投递最高修订号，不依赖 RSS 顺序或发布时间。旧记录显示“已被新版取代”，后续刷新不会再次投递；缺少可靠身份信息时仍需审核。

系统管理的旧版入库后出现更高修订版，自动替换流程如下：

1. 新版先在 `.mooncell/<新 info-hash>` 中独立下载。
2. qBittorrent 确认所选文件完整，且未处于校验或异常状态后，暂停旧种子，并将旧文件移至独立备份目录。
3. 将新版移入媒体库，确认入库后再删除备份目录中的旧种子和旧文件。
4. 新版入库失败时恢复旧版，保留新版暂存文件并进入审核。

各阶段持久化保存，服务重启可继续。合集、跨订阅、规格不同、目录被手动改变或多个任务共享文件时，不自动替换。

## 人工审核

“审核”页读取真实待审核发布和下载整理异常，支持搜索、重新解析、忽略及修正批准。

| 操作 | 行为 |
| --- | --- |
| 修正批准 | 可修正媒体库番名、季度和集数；特别篇可使用季度 0，修正仅对该发布生效 |
| 逐文件修正 | 合集或无法识别文件集数的任务，获取种子元数据后可逐文件填写集数或选择跳过 |
| 批准 | 继续下载队列，仍检查目标文件冲突，不覆盖已有同名文件 |
| 忽略 | 暂停已有任务并保留文件，后续订阅刷新不会重复投递该条目 |
| 重新解析 | 更新解析证据，仍需明确批准 |

操作及批准前后的解析信息保存到事件日志。

## 异步任务提醒中心

顶部右上角的铃铛保存添加订阅后的 TMDB 刮削、修改 TMDB 关联、修改番名或季度引发的文件迁移，以及手动重新刮削的后台结果。提交后可以继续浏览页面，这些操作的后续结果不再弹出 toast。

新增下载任务（RSS 自动入队或磁力合集）以及任务进入人工审核时也会产生未读提醒；重复刷新订阅、队列重试不会重复创建提醒。新增下载提醒提供“查看下载”，待审核提醒提供“前往审核”；批准或忽略后，审核提醒同步更新并标为已读，服务重启保留待审核状态。

- “进行中”显示排队、运行或需要处理的操作；“最近提醒”保留完成、部分完成、失败与取消记录，支持加载更多。
- 一次修改涉及多个下载任务时只显示一条记录，进度单位为下载任务。所有任务恢复原运行状态并保存最终计划后才报告完成。
- 普通进度不增加未读；完成、部分完成、失败或新的受阻原因会增加未读。持续重试相同问题不会重复提醒，处理受阻问题后队列会继续尝试。
- 打开面板不会自动标为已读，可逐条标记或使用“全部已读”。已读状态跨刷新和设备保持；标记过程中产生的新结果仍保持未读，角标超过 99 时显示 `99+`。
- “查看番剧”和“相关日志”会定位到对应记录。删除订阅后仍保留名称和历史，未完成操作取消，关联入口提示订阅已删除。
- 服务重启后文件迁移继续执行；进程内刮削中断会显示失败，请通过番剧页的“重新刮削”重新提交。

用户操作提醒只提供给发起者；自动下载与审核提醒提供给本站唯一管理员。不自动展开面板或播放声音；RSS 自动轮询未产生新任务以及文件移动的各个阶段不会各自生成提醒。表单保存错误仍显示在表单内，其他即时操作保留原有反馈。

## TMDB 配置

在“设置 → TMDB 元数据与图片”中填写 **TMDB API 读访问令牌**或 **API 密钥**，任选其一；同时配置时优先使用读访问令牌。凭据可在 [TMDB 账户 API 设置](https://www.themoviedb.org/settings/api)中获取，保存后立即用于后续请求。

- 搜索、作品详情和图片列表通过官方 v3 API 获取。
- 凭据使用应用的 `MOONCELL_SECRET_KEY` 加密后保存在数据库中，设置页面仅显示配置状态。
- 输入留空保留原值；勾选清除后保存，可移除对应凭据。
- 已有订阅不会自动重抓；在番剧页点击“重新刮削”可更新元数据和图片。
- 总集数取电视详情的 `number_of_episodes`，表示作品总集数，不按订阅季度筛选。
- 首次运行新版本时会自动创建 TMDB 配置表。

## 季度追番日历

### 季度与刷新

追番日历从 yuc.wiki 获取季度新番，按北京时间将当前月份映射到 `YYYY01`、`YYYY04`、`YYYY07`、`YYYY10`。例如 2026 年 9 月读取 `202607`，10 月 1 日起读取 `202610`。

后端运行期间自动检查季度切换；停机错过节点时，下次启动会补抓当前季度。日历包含周一至周日和“其他放送”，后者收录网络放送等非固定星期的作品，显示源站提供的放送日期与说明。

每季度页面成功保存后不再重复抓取，失败的封面单独重试下载。旧版缓存会在后台检查或首次访问时重新抓取一次，补齐“其他放送”，保留已有条目 ID、收藏和封面；补抓失败时仍可浏览旧数据，15 分钟后重试。完成补齐后，浏览日历只读取本地缓存。上一季度按钮首次访问尚未缓存的季度时，会抓取并保存该季度。

### 缓存位置

番名、星期、播出时间保存到 `backend\data\calendar\YYYYMM\season.json`，封面保存在同目录。Docker 中随 `/app/data` 数据卷持久化，可通过 `MOONCELL_CALENDAR_CACHE_PATH` 修改缓存目录。

播出时间保留源站原文，包括表示次日凌晨的 `24:00`、`25:00` 等写法。

### 抓取失败处理

源站暂不可用或尚未发布时，15 分钟后重试。页面和封面请求默认使用环境代理；HTTPS 证书校验失败时会保留证书校验，自动尝试直连一次。

若仍然失败，请检查系统时间及源站、代理证书。重启后端可清除失败后的 15 分钟等待并立即重试。
