# 番剧 / 电影详情页实施计划

日期：2026-10-17。状态：已实施，接口、构建及浏览器验收记录见文末。

## 1. 已选设计与交付目标

采用本轮生图中**第二张展示的设计稿「海报双栏」**，作为唯一视觉基准。

![第二版详情页设计](design/show-detail-v2.png)

- 设计稿实际尺寸为 1487 × 1058；桌面实现保持其比例、留白、字体层级和左海报 / 右内容结构，适配不同视口。
- 顶部沿用 Mooncell 导航；内容区左侧约占三分之一，展示大海报、管理图片入口与素材状态；右侧展示标题、元数据、剧情简介、操作区及页签。
- 右侧背景使用该作品的 `fanart`，加遮罩保证文字对比度；主按钮为“打开文件夹”，辅助按钮为“查看下载”，其余操作放入更多菜单。
- 右下方默认展示“发布资源”，另一个页签为“订阅信息”。资源行保持设计稿中的缩略图、标题、技术信息和状态层级。
- 保留现有黑绿配色、字号体系、Lucide 图标及小圆角，复用已有组件。
- 同一页面支持电视剧和电影；首版详情实体仍是**订阅源 `source_id`**，不按 TMDB ID 合并不同订阅或多季。

设计稿为内置 Image Gen 生成；生成方向摘要：基于现有 Mooncell 界面、真实番剧字段和操作，使用 Emby 式媒体详情构图，以大型左侧海报和右侧资料 / 发布资源构成双栏。

### 必须落实的数据语义

- “已发现 N 条发布”表示资源条目数量，不表示已下载或已入库集数；与 TMDB 总集数分开显示。
- 设计稿中的资源缩略图使用**同一作品背景图的裁切**，无背景图则用海报或现有图标兜底，不作为单集剧照呈现。
- “素材已就绪”必须由 `poster_ready`、`fanart_ready`、`clearlogo_ready` 实际状态决定；缺失时准确显示“2 / 3 项素材已就绪”等状态。
- 无评分、无元数据、未知集数等字段不补造默认值；电影不显示“共 N 集”。
- 首版只显示资源发现与解析状态。`DownloadJob.state=done` 不能当作下载完成；实时下载状态继续由下载中心提供。
- 本期不增加播放、观看进度、已看标记、演职员、单集剧情或剧照等未建模功能。

## 2. 现有能力与需要补齐的部分

| 内容 | 现有来源 | 实施方式 |
| --- | --- | --- |
| 名称、简介、上映 / 首播日期、评分、媒体类型、总集数 | `ShowRead` / `ShowMetadata` | 详情接口复用现有序列化逻辑 |
| TMDB 类型标签、评分人数、刮削时间 | `ShowMetadata.genres_json`、`vote_count`、`scraped_at` | 详情接口新增字段，按有值展示 |
| 海报、背景、透明 Logo、图片版本 | `ShowArtwork` 及现有 artwork 接口 | 使用现有图片地址及版本参数 |
| 订阅类型、季、启用状态、刷新间隔、检查时间、排除词 | `FeedSource` / `FeedRead` | 详情返回 `subscription`，供订阅页签和编辑弹窗使用 |
| 资源原始标题、发布时间、解析后的季集 / 编码等 | `FeedItem` / `ParsedRelease` | 新增结构化分页资源接口 |
| 文件夹、图片上传、重新刮削、订阅编辑 | 现有 POST / PATCH 接口与组件 | 直接复用，补充详情缓存刷新 |
| 按作品查看下载 | 下载页已有 `source_id` 查询参数 | 链接 `/downloads?source_id={id}`，无需改下载接口 |

预计无需数据库迁移，也无需新增前端依赖。

## 3. API 契约

### GET `/api/v1/shows/{source_id}`

新增 `ShowDetailRead`，沿用 `ShowRead` 所有字段，增加：

```typescript
type ShowDetail = Show & {
  subscription: Feed
  genres: string[]
  vote_count: number | null
  metadata_scraped_at: string | null
}
```

实现要求：

- 继续使用 `require_user`，校验订阅是否存在，不存在返回 404。
- 从一个订阅及其元数据、图片关系读取详情，单独聚合该源的资源数量；不为详情加载整个番剧列表。
- 复用 `_show_read` 的图片就绪与版本计算，避免详情和列表显示不同状态。
- `genres_json` 缺失或历史数据不合法时返回空数组；元数据尚未建立仍返回可用的基本详情。
- 详情读取仅访问数据库和本地图片状态，不触发 TMDB 刮削、下载器轮询或任何写操作。

### GET `/api/v1/shows/{source_id}/releases?page=1&page_size=20`

新增分页结构，默认每页 20 条，`page >= 1`、`1 <= page_size <= 100`。

```typescript
type ShowRelease = {
  id: number
  title: string
  published_at: string | null
  discovered_at: string
  parse_status: string
  parsed: ParsedRelease | null
}

type ShowReleasePage = {
  items: ShowRelease[]
  total: number
  page: number
  page_size: number
}
```

实现要求：

- 严格按 `source_id` 查询，返回稳定排序：`published_at DESC NULLS LAST`、`discovered_at DESC`、`id DESC`。
- 合集和修订版按原始资源条目保留，不按集号去重，不把一个合集虚拆成多条资源。
- 解析 `parse_data` 时使用 `ParsedRelease` 校验；失败返回 `parsed: null`，保留原始标题，单条坏数据不阻断整页。
- 资源标题、技术参数、发布日期全部来自记录；解析数据缺失时只呈现可确认的字段。
- 空资源返回 `items: []` 和 `total: 0`；不存在的订阅返回 404，二者区分。
- 页码超过末页返回空列表及真实总数，前端在数据刷新后修正当前页。
- 保留 `/shows/{source_id}/items` 的 `list[str]` 契约，确保现有标题弹窗和测试继续有效。

## 4. 路由与入口

- 新增前端路由 `/shows/:sourceId`，使用独立懒加载页面和对应骨架屏。
- `/shows` 继续作为番剧浏览页。卡片和逐行卡片的海报 / 标题可点击进入详情，内部操作按钮不嵌套在链接里。
- 首页轮播图与“最近添加”跳转详情；轮播图中的“查看下载”文案同步改为“查看详情”。详情内提供明确的下载入口。
- 提醒中心“查看番剧”跳转详情；关联源已删除时保留既有提示。
- 旧链接 `/shows?id=6` 通过 `replace` 跳转 `/shows/6`；旧 `q` 搜索条件可作为返回列表参数保留，`/shows?q=...` 搜索行为继续正常。
- 从列表进入时记录已知的本地返回地址、查询词、视图和滚动位置；返回时恢复。直接打开详情则回到 `/shows`，不盲目调用浏览器后退。
- 对非法 ID、源被删除、首次加载失败提供各自的状态页及返回 / 重试入口。

### AppShell 适配

- 详情页使用全宽内容区，隐藏 `SystemRail`，移除宽屏为侧栏预留的 300px 列；仅作用于详情路由。
- `/shows/:id` 下“番剧”导航保持高亮，补齐窄屏“更多导航”当前项的路径前缀匹配。
- 详情页独立控制左右内边距与背景，避免现有 `.content-stage` 和页面过渡叠加造成双重位移。

`ShowDetailPage` 内的海报区、概览和订阅信息可先保留为局部组件，不为小段静态结构额外建文件。

### 海报与概览

- 左侧固定海报比例 2:3，桌面宽度约 320–400px，按可用空间自适应；图片保持比例，不拉伸。
- 右侧内容用中文标题为主，标题可自然换行；不强制显示未持久化的原文标题。
- 评分、媒体类型、首播 / 上映年份、总集数按实际字段组合，日期缺失不展示伪年份。
- 简介在桌面保持舒适行宽；长简介提供“展开 / 收起”，展开后不覆盖下方操作。
- 主操作区固定顺序：打开文件夹、查看下载、更多。
- “管理图片”复用 `ArtworkUpload`；更多菜单提供编辑订阅、重新刮削、RSS 刷新及 TMDB 外链。
- RSS 刷新只对 `mikan` / `standard` 展示；`magnet` 合集不提供此动作。

### 发布资源

- 页签名使用“发布资源”，总数来自资源接口 `total`。
- 资源主要标题保留原始发布名，辅助行显示已识别的季集范围、字幕组、分辨率、来源、音视频编码、字幕语言。
- 电影资源使用“电影资源”或实际发布名；未知解析使用原始标题，不默认伪装成第 1 集。
- 正确支持特别篇第 0 季、小数集号、集范围、合集及修订版；显示层不取整、不强行补季号。
- 空字幕语言数组表示未识别；仅数据明确标注时显示“无字幕”。
- 缩略图复用作品图片，使用 `alt=""` 作为装饰；无图时使用资源图标和已知集号。
- 首版状态使用“已发现”；解析失败附带“解析信息不可用”，不渲染下载百分比或可播放状态。
- 每页使用已有 `Pagination`；详情变化时重置到第 1 页，资源请求失败只影响资源区。

### 订阅信息

- 显示来源类型、启用状态、指定季 / 自动识别、刷新间隔、最近检查、连接状态及排除关键词。
- `magnet` 使用“磁力合集”的文案，隐藏定时刷新与 RSS 检查类字段；可见编辑操作复用现有合集分支。
- 点击“编辑订阅”复用 `EditSubscriptionDialog`，保存后详情、列表、资源和提醒状态同步刷新。

## 6. 加载、缓存和动效

- 查询键采用 `["shows", "detail", sourceId]` 和 `["shows", "releases", sourceId, page, pageSize]`，继续受现有 `["shows"]` 前缀失效机制覆盖。
- 详情页冷启动直接读取单条详情；不将列表里的不完整 `Show` 对象冒充完整详情缓存。
- 现有 SSE `useEvents` 可刷新上述查询；编辑、图片上传、刮削完成后检查详情是否正确更新，保留当前已显示内容等待后台刷新。
- 先加载元数据并固定海报布局；只协调当前详情所需图片的加载，不等待整个媒体库。图片失败有就地降级，不能导致详情持续停在骨架屏。
- 图片统一附带 `artwork_version`；上传新图片后能看到新版本，切换作品时不闪现上一部海报。
- 海报、右侧概览及资源行使用克制的淡入；边框和内容置于同一个动画容器，避免此前“空边框先出现”的问题。
- 已显示资源在后台刷新、分页切换或图片更新时不整页重播入场；遵守 `prefers-reduced-motion`。

## 7. 响应式与可访问性

- 宽屏约 1100px 以上保持第二版双栏；中等宽度收紧海报列与列间距。
- 小于约 760px 改成海报 + 基础信息的紧凑头部，简介、操作、资源顺序下排，按钮按空间换行。
- 在 390px / 320px 宽度测试长标题、长资源名、技术字段和菜单，不出现水平滚动。
- 主标题只有一个 `h1`；返回入口、TMDB 链接、图片管理和更多菜单均可键盘访问。
- 页签采用语义化 tab 模式并支持方向键；切换时保留合理焦点。
- 海报有作品名称替代文本，背景与资源装饰图为空替代文本；所有错误和加载提示具有适当的状态语义。

- 详情内容改为作品目录实际视频，季度页签例如“第 2 季 · 12”，仍保留“订阅信息”；默认选择订阅指定季度。

- 合集不从资源范围生成单集：本例 Season 02 目录确有 12 个视频，因此显示第 1–12 集；一个包含 01–12 的单独视频仍只显示一个范围文件。
- 保留现有 releases / items API 契约供兼容使用。顶部本地数量来自实际文件数，TMDB 总集数继续独立显示。
