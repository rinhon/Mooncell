# 异步任务提醒中心实施记录

日期：2026-10-15。设计依据：[实施计划](notification-center-plan.md)。原计划文末的“本轮不修改业务代码”描述计划编写阶段；用户随后授权开始实施，本记录描述实现结果。

## 已实现

- 新增 `BackgroundOperation`、`BackgroundOperationItem`，通过现有数据库初始化路径创建，保留原数据库和订阅数据。
- 提醒列表、摘要、详情与子项分页、单条已读、全部已读接口均校验登录和操作归属。已读更新使用数据库条件表达式，旧版本已读请求不会吞掉新结果。
- 添加订阅、更换 TMDB 关联、手动重新刮削均在保存后启动后台操作。手动重新刮削返回 202 和当前番剧数据、操作 ID；提交错误在页面展示。
- 刮削图片先保存在独立暂存目录，核对当前操作、番名和 TMDB 关联后再应用。新的请求取消旧操作，元数据请求失败时保留此前已成功保存的字段。
- 文件迁移按一次订阅修改创建批次，子项以下载任务和迁移 token 关联。完成数从子项汇总，只有 restore 确认、最终计划保存后才计入完成。零个迁移任务不创建提醒。
- 需要处理的迁移问题有明确分类；网络等暂时异常继续等待重试，受阻恢复和最终完成更新原记录。下载任务被移除或忽略时也会重新汇总，避免一直停留在运行中。
- 事件在业务事务中记录，提交成功后通过公共函数广播。迁移完成及失败日志携带操作 ID，支持准确定位该批次的日志。
- 顶部铃铛支持未读角标、进行中和最近提醒、分页、单条及全部已读、错误重试、相关番剧/下载/日志入口、移动布局和键盘操作。
- SSE 变化、连接/重连、窗口焦点恢复触发查询，并每 15 秒补查提醒，避免创建和完成事件同时漏收时丢失提醒。活动任务或连接异常时同步补查业务数据。
- 移除所迁移后台操作的完成 toast，普通字段修改和其他即时操作保留原有反馈。退出登录时取消提醒查询并清除缓存。
- 删除订阅保留名称和历史，取消未完成操作并清空关联；服务启动时继续汇总迁移，遗留刮削显示中断失败并可在番剧页重新提交。

## 环境与边界

- `pnpm` 启动器存在 `shim integrity check failed`，沙箱也会阻止依赖 junction 的真实路径解析。通过 `npm.cmd exec` 按现有锁文件运行 pnpm，并在沙箱外通过 `npm.cmd run build`；未变更依赖版本或锁文件。具体命令见 [开发说明](DEVELOPMENT.md)。
- 本次涉及的文件通过静态检查；仓库其他已有测试文件仍存在格式检查问题，没有顺带修改这些文件。
- 后台刮削仍使用进程内任务，重启后显示中断失败，不自动恢复执行；文件迁移继续使用已有持久化队列。首次运行本版本时自动创建提醒表。
